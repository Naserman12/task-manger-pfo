# 📌 Task & Group Management System

نظام لإدارة المهام والمجموعات تم تطويره باستخدام **Laravel** و **Livewire**.  
يوفر النظام لوحة تحكم سهلة الاستخدام لإدارة الأعضاء، المهام، والإشعارات الديناميكية.  

---

## 🚀 المميزات

- 👥 **إدارة المجموعات**: إنشاء مجموعات جديدة، دعوة الأعضاء، قبول/رفض الدعوات.  
- 📋 **إدارة المهام**: إضافة، تعديل، وحذف المهام مع تعيين المستخدمين.  
- 🔔 **الإشعارات الديناميكية**: 
  - دعوات الانضمام للمجموعة.  
  - إشعار عند قبول أو رفض الدعوة.  
  - إشعارات تعيين المهام وتحديث حالتها.  
  - إشعارات ترحيبية عند التسجيل.  
- 🕵️ **البحث والتصفية**: إمكانية البحث في المهام وتصفيتها حسب الحالة.  
- 🌐 **البث المباشر (Broadcast & Livewire)**: الإشعارات تظهر فورًا دون تحديث الصفحة.  

---

## 🛠️ التقنيات المستخدمة

- [Laravel 11](https://laravel.com/)  
- [Livewire](https://laravel-livewire.com/)  
- [TailwindCSS](https://tailwindcss.com/)  
- Notifications (Database + Broadcast)  
- MySQL (أو أي قاعدة بيانات مدعومة)
